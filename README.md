# Next.js Project Starter

This repository contains a Next.js 16 project created with the App Router, TypeScript, Tailwind CSS, and ESLint.

## Available Scripts

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

Run the project smoke tests:

```bash
npm test
```

Run lint checks:

```bash
npm run lint
```

## Project Structure

- `src/app`: App Router entrypoints, layout, page, and global styles
- `public`: Static assets
- `tests`: Lightweight project setup smoke tests

Open `http://localhost:3000` after running `npm run dev` to view the app.
