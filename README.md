# Next.js Project

Fresh Next.js 16 starter built with the App Router, TypeScript, Tailwind CSS,
ESLint, and Vitest.

## Scripts

```bash
npm run dev
npm run lint
npm run test
npm run build
```

## Development

Start the development server:

```bash
npm run dev
```

Then open `http://localhost:3000`.

The main page lives at `src/app/page.tsx`.
