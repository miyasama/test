# Next.js Project Starter

This repository contains a Next.js 16 App Router project created with TypeScript.

## Scripts

```bash
npm run dev
npm run lint
npm test
npm run build
```

## Stack

- Next.js 16
- React 19
- TypeScript
- ESLint
- Vitest with Testing Library

## Project Structure

- `src/app` contains the App Router entrypoints
- `src/__tests__` contains the UI smoke test
- `vitest.config.mts` configures the test runner
